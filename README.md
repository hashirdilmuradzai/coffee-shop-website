# Coffee Shop Website

A modern and responsive **Coffee Shop Website** developed using **HTML5, CSS3, Bootstrap, and JavaScript**.

This project was created as a frontend development practice project to build a visually appealing coffee shop website with a professional layout, responsive design, branch information, product/coffee sections, customer reviews, and interactive UI elements.

---

## ☕ About The Project

The **Coffee Shop Website** is a frontend website designed for a modern coffee shop or café business.

The website focuses on creating a warm, attractive, and professional online presence for a coffee brand.

It includes a responsive homepage with different sections for showcasing the coffee shop, its products, branches, designs, customer reviews, and other business information.

The project was developed using traditional frontend technologies without using frameworks such as React, Vue, or Angular.
